# AnimeTracker

A personal anime watchlist project built with React. I started it as a way to learn React and gradually added features like AniList search, watch tracking, ratings, filtering, and theme preferences.

---

## Features

- Anime search powered by AniList API
- Add, edit and delete anime
- Watch status and personal ratings
- Search, filter and sort your list
- Dark and light themes
- Persistent storage with localStorage
- Responsive design
